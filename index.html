모두의 웹툰 Every Webtoon

네이버·카카오 웹툰을 TV처럼 한곳에 담아, 회차를 내려받아 오프라인에서도 이어서 감상하는 네이티브 macOS 앱입니다.

설치 & 빌드 소스 보기
Features

브라우저 탭 대신, 네이티브 리더

디스커버리

전체보기·요일별·랭킹·장르·베스트 도전·신작·완결까지 두 플랫폼을 통합 탐색합니다.

리더

세로 스크롤, 폭 맞춤, 화살표 회차 이동과 비동기 이미지 + 메모리 캐시.

자동 스크롤 · 정주행 · 여백/보폭 설정

다운로드

회차별 병렬 다운로드, 진행률/속도/ETA 표시, 즉시 취소, 재다운로드 스킵.

보관함 & 이어보기

다운로드 목록·최근 본 관리와 SQLite 메타데이터 캐싱. 스크롤 위치 저장으로 98% 자동 다음화.

컬렉션

맞춤 모음으로 웹툰을 정리하고, 다운로드 여부 배지와 신규 회차 업데이트 감지.

내보내기 & 백업

회차별 CBZ / EPUB 내보내기와 메뉴바 단축키로 백업·복원.

Install

빌드 & 실행

# 최초 1회 — venv + 의존성
./scripts/install_python_deps.sh

# 빌드 → 배포 → 실행
./scripts/build_and_run.sh debug macos
./scripts/build_and_run.sh release macos

요구 사항

  • macOS 14+ (Sequoia 권장)
  • Python 3.11+ — 검색·메타데이터 백엔드
  • 번들 ID — com.borasarang.everywebtoon
  • 저장 경로 — ~/Documents/EveryWebtoon/
