Key features

브라우저가 아니어도 좋은 이유

검색부터 감상, 오프라인 보관까지 — 한 번의 흐름으로 이어집니다.

디스커버리

전체·요일별·랭킹·장르·베스트 도전·신작·완결. 네이버와 카카오를 한 화면에서 둘러봅니다.

몰입형 뷰어

세로 스크롤, 폭 맞춤, 공백·화살표 단축키. 이미지는 비동기 로딩과 메모리 캐시로 부드럽게.

오프라인 다운로드

회차별 병렬 다운로드, 진행률·속도·ETA, 즉시 취소, 재다운로드 스킵까지.

이어보기

스크롤 위치를 저장하고 98% 지점에서 다음 회차로 자연스럽게 이어집니다.

CBZ · EPUB 내보내기

회차를 파일로. 전자책 리더나 구독형 뷰어 어디서든 감상할 수 있습니다.

설정과 백업

저장 위치·캐시 TTL·신규 회차 알림. 메뉴바에서 즉시 백업과 복원.

Install

오픈소스, 직접 빌드해 보세요.

macOS 14 이상에서 소스를 내려받아 실행할 수 있습니다. 배포용 아이콘과 번들 스크립트가 준비되어 있습니다.

# 최초 1회 — 의존성
./scripts/install_python_deps.sh

# 빌드 → 배포 → 실행
./scripts/build_and_run.sh debug macos
